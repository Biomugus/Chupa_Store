## TP-04: Выбор платформы

| Шаг | Действие                           | Ожидание                                                          |
| --- | ---------------------------------- | ----------------------------------------------------------------- |
| 1   | Нажать карточку «АК / АКМ»         | Карточка выделена gold-обводкой + ✓, статус «Платформа сохранена» |
| 2   | Проверить блок «Текущая платформа» | Появился блок с текстом «АК / АКМ»                                |
| 3   | Перезагрузить страницу             | Выбор сохранён, «АК / АКМ» по-прежнему выделена                   |
| 4   | Нажать «АК / АКМ» повторно         | Выбор снят (toggle), блок «Текущая платформа» исчезает            |
| 5   | Выбрать «АКСУ»                     | Карточка «АКСУ» выделена, статус «Платформа сохранена»            |

**Статус:** ☐ Пройден / ☐ Не пройден

## TP-05: Бейджи совместимости — залогиненный с платформой

| Шаг | Действие                               | Ожидание                                        |
| --- | -------------------------------------- | ----------------------------------------------- |
| 1   | В `/account` выбрать «АК / АКМ»        | Сохранено                                       |
| 2   | Перейти в `/catalog`                   | На карточках товаров видны бейджи               |
| 3   | Проверить «Упор»                       | ✅ Совместимо (зелёный бейдж)                   |
| 4   | Проверить «Укорот»                     | ⚠️ Потребуется напилинг (жёлтый)                |
| 5   | Вернуться в `/account`, выбрать «АКСУ» | Сохранено                                       |
| 6   | Перейти в `/catalog`                   | Бейджи обновились                               |
| 7   | Проверить «Укорот»                     | ✅ Совместимо (теперь perfect для АКСУ)         |
| 8   | Проверить «Упор»                       | ⚠️ Потребуется напилинг (modification для АКСУ) |

**Статус:** ☐ Пройден / ☐ Не пройден
